# AJ Medical Equipment Trading - Official Website

An exact, pixel-perfect, and fully interactive web application built with **Next.js 14**, **React**, and **Vanilla CSS** matching the design layouts provided in `AJ_Medical_Pagewise_Full_Website_Layouts.pdf`.

---

## 🚀 Live Pages Implemented

| Page | Route | Description |
| :--- | :--- | :--- |
| **Home** | `/` | Header, Hero, Services Grid, Why Choose AJ Medical, Hospitals That Trust Us, CTA & Footer |
| **About Us** | `/about` | Dark Hero, Our Story (Mission, Vision, Values), What Drives Us, Global & Regional Reach (UAE, GCC, Africa), Facility stats & updates |
| **Services** | `/services` | Specialized Healthcare Services, Technical Expertise, 4-Step Maintenance Process, Support CTA |
| **Endoscopy Repair** | `/services/endoscopy-repair` | Service deep-dive: Flexible & Rigid scopes, Common issues we repair, Repair process, Quality guarantees |

| **Blog** | `/blog` | Biomedical engineering insights, equipment care articles, and clinical updates |
| **Contact Us** | `/contact` | Working interactive inquiry form, Dubai Al Quoz interactive map modal, direct calling & WhatsApp links |
| **Privacy Policy** | `/privacy` | Legal & confidentiality standards for clinical client data |
| **Terms of Service** | `/terms` | Equipment repair warranty and service engagement terms |

---

## 🛠️ Key Features

- **Interactive Modals**:
  - `ConsultationModal`: Interactive request dialog for quotes, service inquiries, and repairs.
  - `SearchModal`: Real-time instant search across all services, equipment, and pages.
  - `MapModal`: Interactive Google Maps view of the Dubai workshop and headquarters.
- **Interactive Form**: Contact form with live state validation, input handling, and toast notification feedback.
- **Carousel Controls**: Working navigation arrows (`←` and `→`) for services and hospital partner showcases.
- **Responsive Navigation**: Sticky navbar with active route indicator, mobile drawer menu, search button, and consultation CTA.
- **Exact Visual Assets**: 100% faithful representation of colors, typography, curved organic frames, icons, and badges from the source PDF.
